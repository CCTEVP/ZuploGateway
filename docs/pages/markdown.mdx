# Quick Reference

## Weather

```http
GET /weather/sweden?latlon=59.339,18.067&format=json
```

```http
GET /weather/norway?player=582309742&format=json
```

```http
GET /weather/norway?com.broadsign.suite.bsp.resource_id=582309742&debug=true&format=json
```

```http
GET /weather/sweden?latlon=59.339,18.067&filter=false&format=json
```

```http
POST /weather/sweden/reset
```

```http
POST /weather/norway/reset
```

## Flights Norway

```http
GET /flights/norway?player=582309742&format=json
```

```http
GET /flights/norway?player=759244535&direction=D&format=json
```

```http
GET /flights/norway?gate=D1&iata=OSL&direction=D&format=json
```

```http
GET /flights/norway?com.broadsign.suite.bsp.resource_id=582309742&format=json
```

```http
POST /flights/norway/reset
```

## Response format

Default (JavaScript):

```javascript
data = { /* payload */ };
```

With `format=json`:

```json
{ "timestamp": "...", "...": "..." }
```

### Flights success (filtered) fields

- `iata` / `airportCode`
- `direction`
- `gate`
- `flights[]` — includes `flightId`, `airline`, `scheduleTime`, `airport`,
  `airportName`, `gate`, `beltNumber`, `status`, `delayed`, …
- `attribution`
- `timestamp`

### Common errors

| Status | When |
| --- | --- |
| 400 | Missing params, `gate`+`player` together, player has no gate, invalid direction/format |
| 404 | Unknown player id |

## Sample client

Save a flights JS response to:

```text
bsp/sync/bmonorway/flightsdata.js
```

as:

```javascript
data = { /* paste Zuplo /flights/norway body */ };
```

Then open `samples/v1/index.html` (1080×1920 board).
