# Quick Reference

## Weather

```http
GET /weather/sweden?latlon=59.339,18.067&format=json
```

```http
GET /weather/norway?player=582309742&format=json
```

```http
GET /weather/norway?resource_id=582309742&debug=true&format=json
```

```http
GET /weather/sweden?latlon=59.339,18.067&filter=false&format=json
```

```http
POST /weather/sweden/reset
```

```http
POST /weather/norway/reset
```

## Flights Norway

Player lookup:

```http
GET /flights/norway?player=582309742&format=json
```

```http
GET /flights/norway?player=759244535&direction=D&format=json
```

```http
GET /flights/norway?resource_id=582309742&format=json
```

Direct lookup (`gates` + optional `iata`):

```http
GET /flights/norway?gates=D1&iata=OSL&direction=D&format=json
```

```http
GET /flights/norway?gates=C34,C35&iata=BGO&format=json
```

```http
POST /flights/norway/reset
```

## Response format

Default (JavaScript):

```javascript
data = { /* payload */ };
```

With `format=json`:

```json
{ "timestamp": "...", "...": "..." }
```

### Flights success (filtered) fields

- `iata` / `airportCode`
- `direction`
- `gates`
- `flights[]` — includes `flightId`, `airline`, `scheduleTime`, `airport`,
  `airportName`, `gate`, `beltNumber`, `status`, `delayed`, …
- `attribution`
- `timestamp`

### Common errors

| Status | When |
| --- | --- |
| 400 | Missing params, `gates`+`player` together, invalid gates, player has no gate, invalid direction/format |
| 404 | Unknown player id |

## Sample client

The **1080×1920** board is at `/samples/v1/index.html` in the docs portal.
It calls the live gateway and forwards `player`, `resource_id`, `gates`, and
`iata` from the page URL, for example:

```text
/samples/v1/index.html?resource_id=759244535&direction=D
/samples/v1/index.html?gates=D9&iata=OSL&direction=D
```
