# Weather Endpoint Quick Reference

Use this page for copy-paste request patterns and expected response shape.

## Request Patterns

```http
GET /weather/?latlon=32.46564,12.8737874
```

```http
GET /weather/?player=123456&format=json
```

```http
GET /weather/?com.broadsign.suite.bsp.resource_id=123456&format=json
```

```http
GET /weather/?latlon=32.46564,12.8737874&debug=true&format=json
```

```http
GET /weather/?latlon=32.46564,12.8737874&filter=false&format=json
```

```http
POST /weather/reset
```

## Response Format

Default response is JavaScript:

```javascript
data = { ...payload };
```

With format=json:

```json
{
  "coord": { "lon": 12.874, "lat": 32.466 },
  "main": { "temp": 19.7 },
  "weather": [{ "main": "Clouds" }],
  "wind": { "speed": 3.6 },
  "rain": { "1h": 0.12 },
  "timestamp": "2026-05-19T11:18:22.000Z"
}
```

## Filtering Rules

- By default, weather payload is filtered.
- Set filter=false to return the full upstream payload.
- timestamp is always returned.
- debug is only returned when debug=true.

## Status Codes

| Endpoint            | Status | Meaning                             |
| ------------------- | ------ | ----------------------------------- |
| GET /weather/       | 200    | Success                             |
| GET /weather/       | 400    | Missing or invalid query parameters |
| GET /weather/       | 404    | Unknown player or resource_id       |
| POST /weather/reset | 200    | Cache version bumped                |
