# Dynode Gateway

Edge API on Zuplo for **weather** (OpenWeather) and **Norway flights**
(Avinor), resolved from Broadsign player datasets.

The [API Reference](/api) is generated from `config/routes.oas.json` and is the
source of truth for parameter schemas.

## Endpoints

### Weather

| Method | Path | Players |
| --- | --- | --- |
| GET | `/weather/sweden` | Sweden + shared test |
| POST | `/weather/sweden/reset` | Cache invalidate |
| GET | `/weather/norway` | Norway + shared test |
| POST | `/weather/norway/reset` | Cache invalidate |

Weather cache TTL: **1 hour**. Requires `OPENWEATHER_API_KEY`.

### Flights

| Method | Path | Notes |
| --- | --- | --- |
| GET | `/flights/norway` | Avinor XmlFeed, gate filter |
| POST | `/flights/norway/reset` | Cache invalidate |

Flights cache TTL: **180 seconds** (~3 minutes per Avinor guidance). No Avinor API key.

## Player resolution

Country datasets: `modules/players/sweden.ts`, `modules/players/norway.ts`.

Shared demo/QA players in `modules/players/test.ts` are merged into **every**
country lookup.

Query aliases for player id:

- `player`
- `com.broadsign.suite.bsp.resource_id`

Optional player fields for flights: `Gate`, `IATA`.

Demo IDs: `759244535` (gate D9 / OSL), `582309742` (gate D1 / OSL).

## Common response behaviour

- Default body: JavaScript `data = {...};`
- `format=json` for raw JSON
- `filter=false` bypasses field allowlist
- `debug=true` adds upstream/debug metadata
- `timestamp` is always present on success payloads

## Flights notes

- Provide **either** `gate` **or** `player` / resource id (not both).
- `direction=D` (default) or `A`.
- `iata` overrides airport (alias `airport`); default player IATA or `OSL`.
- Flights include `airportName` when Avinor airport names resolve.
- Departures match player gates more reliably than arrivals.

## Sample signage client

`samples/v1/` is a 1080×1920 board that reads local
`bsp/sync/bmonorway/flightsdata.js` (Zuplo JS download shape). It does not call
the live gateway at runtime.

## Local examples

```bash
GET /weather/norway?player=582309742&format=json
GET /weather/sweden?player=582607705&format=json
GET /flights/norway?player=582309742&format=json
GET /flights/norway?gate=D9&direction=D&format=json
POST /flights/norway/reset
POST /weather/norway/reset
```
